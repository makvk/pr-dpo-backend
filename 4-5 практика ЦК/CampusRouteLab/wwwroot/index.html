Обязательные маршруты и поведение приложения

Бизнес-маршруты

Маршрут Ожидаемое поведение Формат ответа
/students Вернуть список доступных учебных групп и количество студентов в каждой группе. JSON
/students/ИКБО-30-24 Вернуть информацию по одной группе и список студентов этой группы. Параметр group обязателен. JSON
/students/ИКБО-30-24/1 Вернуть одного студента по группе и идентификатору. Если студент не найден — корректный 404. JSON/404
/reports/{section?} Маршрут с необязательным параметром. Если section не передан, использовать значение overview. Text
/portal/{module=home}/{page=index}/{id?} Маршрут со значениями по умолчанию. В ответе явно показать, какие значения были получены системой маршрутизации. Text
/files/{**path} Catch-all маршрут: вернуть весь захваченный остаток пути после /files/. Text

Диагностические маршруты

Маршрут Ожидаемое поведение Формат ответа
/routes Вывести все зарегистрированные конечные точки приложения через EndpointDataSource. Text
/diag/lifetimes Показать идентификаторы и/или метки времени для singleton, scoped и transient в одном запросе. JSON
/diag/lifetimes/check Внутри одного запроса разрешить сервисы повторно и продемонстрировать, какие значения совпадают, а какие отличаются. JSON
/diag/request-services Получить зависимость через HttpContext.RequestServices.GetRequiredService(...) и вывести результат. JSON
/diag/app-services Получить singleton-сервис через app.Services.GetRequiredService(...) и вывести данные о приложении. JSON
