Маршруты для тестирования конфигурации ASP.NET Core

Таблица содержит все тестовые эндпоинты. Гиперссылки ведут на соответствующие маршруты (относительные пути).

Маршрут Ожидаемое поведение Какая тема проверяется
/ Стартовая страница с кратким описанием проекта и ссылками на тестовые маршруты. Терминальный endpoint
/config/raw Возвращает несколько значений через IConfiguration: например Portal:Title, Portal:SupportEmail, Notifications:Sender. Индексатор IConfiguration и DI
/config/section/portal Показывает данные секции Portal через GetSection(). GetSection
/config/tree Рекурсивно выводит структуру секции Portal или другой выбранной секции. GetChildren и анализ конфигурации
/config/connection Возвращает значение GetConnectionString("DefaultConnection"). GetConnectionString
/config/providers Показывает список провайдеров конфигурации из IConfigurationRoot.Providers. Анализ провайдеров
/config/custom Возвращает значения, считанные собственным провайдером из customsettings.txt. Custom provider
/config/bind Возвращает объект PortalOptions, полученный через Bind() или Get<PortalOptions>(). Проекция на классы
/config/options Возвращает значения из IOptions<PortalOptions> и IOptions<NotificationOptions>. IOptions
/config/effective Показывает итоговые значения конфликтующих ключей и текущее окружение. Объединение источников и приоритеты
